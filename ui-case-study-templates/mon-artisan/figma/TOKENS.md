# Mon Artisan — tokens du poster

## Couleurs

| Style Figma | Hex | Rôle |
|---|---|---|
| `brand/rouge` | `#A82024` | couleur dominante : titres d'accroche, boutons pleins, barres, accents |
| `brand/rouge-profond` | `#7E1219` | première barre de planning, survols |
| `brand/rouge-clair` | `#F3DDDE` | fonds d'étiquette, pastilles |
| `brand/navy` | `#384152` | sections sombres, en-têtes de persona |
| `brand/navy-profond` | `#252C39` | pied de page |
| `brand/creme` | `#EDE9E2` | fond des sections alternées, citations |
| `paper` | `#F7F5F2` | fond des sections claires |

| `ink-2` | `#4A515C` | paragraphes |
| `grey` | `#8A8F98` | étiquettes, légendes |

Rouge, navy et crème sont les trois couleurs déclarées sur le moodboard du projet.
Le rouge a été relevé sur la pastille elle-même (l'étiquette imprimée est illisible
dans le fichier source) ; les deux autres sont les valeurs écrites : `#384152` et `#EDE9E2`.

## Typographie

Le projet utilise **Intro Rust** en display — police commerciale (Fontfabric), absente
de Google Fonts. Le poster utilise **Archivo Black** comme équivalent libre, disponible
dans Figma comme dans le navigateur. Corps de texte : **Archivo** (300–700).

| Style Figma | Taille / graisse | Usage |
|---|---|---|
| `display/h1` | 56 · Archivo Black · MAJ · −2,5 % | titre du hero |
| `display/h2` | 44 · Archivo Black · MAJ · −2 % | titres de section |
| `display/h3` | 21 · 700 | titres de carte |
| `label/eyebrow` | 11,5 · 700 · +20 % · MAJ | « 01 — Le brief » |
| `body/lead` | 17 · 400 · interligne 1,6 | chapô |
| `body/base` | 15 · 400 · interligne 1,65 | paragraphes |
| `body/small` | 13,5 · 400 | tableaux, listes de persona |
| `data/stat` | 30 · Archivo Black | chiffres du bandeau hero |

## Grille & espacements

- Largeur du poster : **1200 px**
- Marges de section : **80 px** horizontal, **76 px** vertical
- Gouttières : **18–26 px**
- Rayons : **8–10 px** (petits blocs) · **14–16 px** (cartes) · **999 px** (pilules)
- Filet de titre : barre pleine **56 × 4 px** en rouge, jamais de trait fin
