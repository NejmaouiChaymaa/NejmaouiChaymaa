## Typographie

Le projet utilise **Canva Sans** — disponible uniquement dans Canva. Le poster
utilise deux polices libres, présentes dans Figma comme sur le web :

| Style Figma | Police | Taille |
|---|---|---|
| `display/h1` | Instrument Serif | 94 · interligne 0,98 |
| `display/h2` | Instrument Serif | 52 · interligne 1,06 |
| `display/chiffre` | Instrument Serif | 26 (valeurs du graphique) |
| `label/section` | Karla 600 · +24 % · MAJ | 10,5 |
| `body/lead` | Karla 400 | 18 · interligne 1,65 |
| `body/base` | Karla 400 | 15 · interligne 1,7 |
| `body/small` | Karla 400 | 12,5–13,5 |

L'italique d'Instrument Serif porte les accents éditoriaux (« vos yeux »,
« Nature » dans le logotype de bas de page) : c'est le seul effet typographique du poster.

## Structure

- Largeur : **1200 px** · hauteur ~6 400 px (le plus court des trois posters)
- Chaque section est une grille **150 px + reste**, gouttière 44 px : la colonne
  de gauche ne porte que le numéro, le libellé et un filet vertical
- Marges : 80 px horizontal, 72 px vertical
- Pas d'arrondis, pas d'ombres : les cartes sont des rectangles à filet 1 px
- Les bandes photographiques sont pleine largeur, sans marge

## Graphique du questionnaire

Barres horizontales, une seule série, donc pas de légende : la valeur est écrite
au bout de chaque barre. Couleur unique `#AABEC6` sur la piste sombre, extrémités
arrondies à 4 px, axe 0–100 % rappelé sous les barres. Les quatre pourcentages
viennent du questionnaire du projet.
